# On The Creation Of Code Mods

Mods can include a `code0adjustments.js` file.
This file is expected to `export default` a function
that takes in the text of a `CommandCode` function from `code0.js`
and return that text, modifed to achieve some effect.

It is expected that you use [the power of regex](https://regexr.com).
Keep in mind that other mods may have gotten to whatever you're trying to modify
first, and that the numbers assigned to objects are not consitent between game
versions.

Since this requires running user submitted js code,
if a mod has a `code0adjustments.js` file,
a symbol will appear next to their name in the mod menu.
In the future, seeing this symbol should hopefully be quite rare
for all but the most complicated mods.

### Prerequisites

- A copy of Hyperspace Deck Command
- [Node.js](https://nodejs.org/en/download)
- (Optional) [7Zip](https://www.7-zip.org/download.html) and [this .asar extension](https://www.tc4shell.com/en/7zip/asar/)

### Extracting an appimage (Linux)

If your copy of Hyperspace Deck Command is the linux build from Itch.io,
the appimage must first be extracted.

Open a terminal and enter the following command:
`[absolute path to AppImage] --appimage-extract`. For example,
`/home/user/Downloads/Hyperspace\ Deck\ Command/Hyperspace\ Deck\`
`Command.AppImage --appimage-extract`.
This will appear to list a series of files in the appimage
then exit without doing anything,
but it has extracted the files to `squashfs-root` in the working directory.

### Extracting the .asar file

Open a terminal inside the `resources` folder
of the directory where your game is installed.

Run `asar extract app.asar [new directory name]` on Windows or
`npx @electron/asar extract app.asar [new directory name]` on Linux
to extract `app.asar`into `[new directory name]`.

Any directory named `app.asar` will be treated as valid by electron. Rename
`app.asar` to something else and the new directory to `app.asar` to easily make
changes to game behavior.

(In Windows Powershell you may first need to run
`Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy Unrestricted`
as an administrator?)

### (Alternative) Extracting with Visual Studio

Visual studio code automatically treats .asar files as read only directories.

### (Alternative) Extracting with 7-Zip

With the 7Zip .asar extension, you can treat app.asar as a zip file.
Right click and extract with 7Zip.

### (Optional) Repacking the .asar file

Run `asar pack [subdirectory name] app.asar` in `resources`
to repack everything contained within the subdirectory back into an asar file.

**Note!**
**To enable console output,**
**uncomment line 46 of main.js:** `mainWindow.webContents.openDevTools()`
**in the extracted app.asar.**
